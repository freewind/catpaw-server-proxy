流式请求

curl -N http://127.0.0.1:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"你好"}],"stream":true}'

指定工作目录

curl -N http://127.0.0.1:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Working-Directory: D:/projects/myapp" \
  -d '{"model":"auto","messages":[{"role":"user","content":"列出当前目录文件"}],"dir":"D:/projects/myapp","stream":true}'

const res = await fetch('http://127.0.0.1:3000/v1/chat/completions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'auto',
    messages: [{ role: 'user', content: '你好' }],
    stream: true,
  }),
});
const reader = res.body.getReader();
const decoder = new TextDecoder();
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const text = decoder.decode(value);
  text.split('\n').forEach(line => {
    if (line.startsWith('data: ')) {
      const data = line.slice(6);
      if (data === '[DONE]') return;
      const chunk = JSON.parse(data);
      const content = chunk.choices?.[0]?.delta?.content;
      if (content) process.stdout.write(content);
    }
  });
}

⚙️ 登录与配置

方式一：扫码登录（推荐）

在上方“扫码登录”区域点击“打开登录页面”，用手机美团 APP 扫码即可完成登录。

方式二：通过 CatPaw 桌面应用登录

启动 CatPaw Electron 桌面应用并使用 SSO 登录，反代服务通过命名管道复用其登录状态。

⚠️ 使用方式二时，CatPaw 应用必须保持运行。

设置工作目录（重要）

Agent 需要知道你的项目路径才能访问本地文件。有三种方式指定：

  • 请求体参数：在 /v1/chat/completions 请求体中传 "dir":"D:/myproject"
  • HTTP 头：添加请求头 X-Working-Directory: D:/myproject
  • 服务器启动参数：node server.mjs --cwd D:/myproject（全局默认）
⚠️ Agent 的文件访问权限由 CatPaw 设置中的沙箱模式控制：
• workspace-write（默认）：仅允许在指定工作目录内读写
• full-access：允许访问整个文件系统

公网部署安全配置（重要）

部署到公网服务器时，务必配置以下安全参数：

node server.mjs \
  --api-key your-secret-key-here \
  --allowed-dirs D:/projects,D:/workspace \
  --callback-url https://your-domain.com/callback
  • --api-key：设置 API Key，客户端需传 Authorization: Bearer your-secret-key-here
  • --allowed-dirs：限制可访问的工作目录（逗号分隔），防止任意目录访问
  • --callback-url：扫码登录回调地址（公网域名），如 https://your-domain.com/callback
⚠️ 公网部署必须设置 --api-key，否则任何人都可以使用你的 API！
建议配合 Nginx 反向代理 + HTTPS 使用，并通过 --allowed-dirs 限制可访问的目录。

创建 evaluation 配置文件（方式二必需）

文件路径: C:\Users\<用户名>\.meituan-catpaw\paw.json
文件内容: {"evaluation":true}

架构原理

┌──────────────────────────────────────────────────────────┐
│  客户端 (ChatBox / LobeChat / curl / OpenAI SDK)        │
│         ↓ HTTP POST /v1/chat/completions                 │
│  反代服务器 (server.mjs, localhost:3000)                  │
│         ↓ HTTP over Named Pipe (\\.\pipe\paw)            │
│  CatPaw Electron 应用 (GUI, 已登录, 复用 SSO 认证)       │
│         ↓ MWS Auth + 内置工具执行                         │
│  CatPaw 后端 (美团 AI 服务)                              │
└──────────────────────────────────────────────────────────┘
